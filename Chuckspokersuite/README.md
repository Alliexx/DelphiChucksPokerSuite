Overview:
Chuck’s Standard Poker Suite is a procedural poker library for Delphi
programmers. It is not Object-Oriented. The Poker Suite supports 3-card, 4-
card, and 5-card poker variants. (An 5-card poker variant is one in which 5
or more cards are dealt into each hand, but only 5 cards from the hand are
used to determine the hand’s evaluation. For example, 7-Card Stud is a 5-
card poker variant, because the best five-card hand taken from the seven
cards is used to determine the winner.) The Poker Suite supports both high
and low hand evaluations. It does not support wild cards. Versions of the
Poker Suite are available for Delphi 1 through Delphi 2005
